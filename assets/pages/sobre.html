Sobre o Projeto

Este é um projeto desenvolvido para a disciplina de Gerência e Configuração de Mudanças do curso de Análise e Desenvolvimento de Sistemas.

O objetivo foi criar um sistema simples de gerenciamento de tarefas (To-Do List) que permite aos usuários adicionar, editar, marcar como concluído e remover tarefas de forma intuitiva.

Objetivos do Projeto

Desenvolver um sistema funcional de gerenciamento de tarefas que demonstre conhecimentos em:

• Manipulação do DOM com JavaScript
• Design moderno
• Estruturação de código limpo e organizado
• Aplicação de conceitos de versionamento
